Decisions that are now fixed

Public, direct leaves

Consumers import an approved workflow or model path directly. The export map is an allowlist; the package has no root public barrel.

feature-workflows/day-logs/save-food-entry

Contract firewall

Private API modules form and validate HTTP requests. Feature workflows map private API values to public frontend-domain models and command inputs.

api/** is not exported

Portable cache behavior

Core owns keys, snapshot composition, mutations, and conditional reconciliation. Apps inject transport, account identity, and QueryClient.

DayLogSnapshot = DayLog | null | undefined

Platform code stays put

IndexedDB persistence, cache lifecycle fences, browser events, router state, WebAuthn adapters, and UI components remain in web.

ADR-0004 privacy fence unchanged

Day Log semantics are preserved

Loaded is a DayLog; Known-empty is null; unloaded is undefined. The refactor does not normalize nullable meal collections yet. It creates the mapper seam first, without changing the cache language that Logs already relies on.

Implementation sequence

1

Mechanical rename

Rename package/workspace metadata and replace root imports with direct temporary leaf adapters. Prove Nx and TypeScript resolution before behavior changes.

2

Seal the boundary

Create private API modules, explicit exports, and configurable credential behavior while retaining today’s include default.

3

Day Log model and workflows

Create domain models/mappers, then move sync, slot composition, food-write, weight-write, and reconciliation logic into portable workflows.

4

Migrate feature consumers

Move Logs/Food Search and Dashboard onto core models; remove the unused legacy dashboard nutrition model only after an import audit.

5

Complete authentication and harden

Introduce AuthenticatedUserContext, keep web session fencing/navigation local, then remove transitional adapters and audit the contract firewall.

Review focus

The deliberately hard-to-reverse choices are recorded in ADR-0007: package identity, no-barrel export rule, private API boundary, feature-workflow mapping, cache ownership, and the web/mobile runtime split. The detailed file-level work is in the staged plan and nine tickets.
